# Work Experience & Internships of Aman Singh Chauhan

## Machine Learning Intern — Placemantra
- **Duration**: March 2025 – May 2025
- **Domain**: Financial Machine Learning & Fraud Detection
- **Key Project**: Online Payment Fraud Detection System

### Key Accomplishments & Metrics:
1. **Large-Scale Data Processing**:
   - Processed and evaluated over 6.3 million financial transaction records.
   - Handled high class-imbalance typical of financial fraud distributions.

2. **Model Performance**:
   - Developed and trained an XGBoost Classifier model.
   - Achieved ~99.96% accuracy and an impressive ROC-AUC score of ~0.963 on the test set and ~0.969 on the training set.
   - Drastically reduced false positives while capturing fraudulent transaction spikes.

3. **Exploratory Data Analysis (EDA)**:
   - Conducted deep EDA using Python, Pandas, Matplotlib, and Seaborn.
   - Uncovered critical fraud distribution patterns across varying transaction types (e.g., TRANSFER, CASH_OUT).
   - Identified abnormal balance shifts and temporal transaction velocity indicators.

4. **Feature Engineering**:
   - Engineered two high-impact custom domain features: `balanceDiffOrig` (origin account balance change) and `balanceDiffDest` (destination account balance change).
   - These features significantly elevated the model's discriminative power between legitimate and fraudulent behavior.
   - Preprocessed categorical features using Label Encoding and applied a strategic 70/30 stratified train-test split for unbiased evaluation.
