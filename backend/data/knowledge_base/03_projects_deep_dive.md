# Projects Built by Aman Singh Chauhan

## 1. Wanderlust — Full-Stack Holiday Rental Platform
- **Tagline**: Full-stack holiday rental platform where hosts can list properties with photos, pricing, and amenities, and guests can browse and book stays.
- **Tech Stack**: Node.js, Express.js, MongoDB, React, EJS, Cloudinary, Passport.js.
- **Key Features**:
  - Secure user authentication and session management using Passport.js.
  - Complete CRUD operations for property listings with image upload support via Cloudinary.
  - Scalable RESTful APIs structured with MVC (Model-View-Controller) architecture.
  - Interactive map and listing filters for travelers.
- **Code Repository**: https://github.com/amansinghchauhan

## 2. FaceLink — Full-Stack Video Conferencing Platform
- **Tagline**: Browser-based video conferencing application supporting real-time peer-to-peer audio, video streaming, and screen sharing across multiple participants simultaneously.
- **Tech Stack**: WebRTC, JavaScript, Node.js, Socket.io, HTML5, CSS3.
- **Key Features**:
  - WebRTC peer-to-peer direct media streaming for low-latency browser communications.
  - Socket.io signaling server managing room creation, participant handshakes, and peer connection negotiation.
  - Dynamic interactive UI controls for microphone muting, camera toggle, screen sharing, and ending calls gracefully.
  - Integrated real-time messaging and chat panel alongside live video conferencing.
- **Code Repository**: https://github.com/amansinghchauhan

## 3. HatchHub — Professional Networking & Community Platform
- **Tagline**: Full-stack professional networking platform featuring user profiles, posts, likes, comments, and a LinkedIn-style connection system.
- **Tech Stack**: React.js, Node.js, Express.js, MongoDB, Socket.io, JWT.
- **Key Features**:
  - Real-time one-on-one instant messaging using Socket.io with full conversation history stored and retrieved from MongoDB.
  - Dynamic personalized feed surfacing posts from accepted connections.
  - Robust authentication secured with JSON Web Tokens (JWT) and protected API routes.
  - User connection system with invite requests, accept/reject workflows, and profile customization.
- **Code Repository**: https://github.com/amansinghchauhan

## 4. Portfolio AI Assistant — RAG-Powered Profile Copilot
- **Tagline**: Interactive cyberpunk AI assistant integrated into Aman's personal portfolio.
- **Tech Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Python, FastAPI, ChromaDB, Sentence Transformers, Google Gemini.
- **Key Features**:
  - Persistent ChromaDB vector store indexing Aman's verified resume and structured profile documents.
  - Semantic retrieval with cosine similarity scoring and citation transparency.
  - Live conversational responses generated using Google Gemini.
  - Beautiful dark cyberpunk UI with glowing accents, suggestion chips, and responsive drawer.
